# Code of Conduct

## Our standard

We want this project to be a respectful, constructive, and welcoming place for contributors.

Expected behavior includes:

- Being respectful and professional.
- Giving constructive technical feedback.
- Focusing criticism on ideas and code rather than people.
- Respecting different experience levels and backgrounds.
- Keeping project discussions relevant.

Unacceptable behavior includes harassment, discrimination, threats, personal attacks, or deliberate disruption.

## Enforcement

Project maintainers may remove or moderate content that violates these standards. Serious or repeated violations may result in loss of participation privileges.

For concerns about conduct, contact the repository maintainer through GitHub.
