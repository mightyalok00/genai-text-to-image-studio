# Security Policy

## Supported scope

Security reports are welcome for the application source code, repository configuration, and dependency-management issues.

## Reporting a vulnerability

Please do not publish sensitive vulnerability details in a public issue.

Use GitHub's private vulnerability reporting/security advisory workflow for this repository when available. If private reporting is unavailable, contact the repository maintainer through the contact options provided by GitHub.

## Never disclose secrets publicly

Do not submit:

- API keys
- Access tokens
- Passwords
- Private credentials
- Private user data
- Local model caches containing sensitive information

The current application does not require an application API key for local inference.
